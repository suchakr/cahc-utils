# Linguistics projects

This folder collects small research and tooling projects related to Sanskrit linguistics and phonetics.

Subprojects

- dhaatu-paatha: an interactive web animation demonstrating Paninian verb derivation (dhaatu -> ti45anta). Open `dhaatu-animation.html` to try it. See `dhaatu-paatha/README.md` for details.
- varna-sanyoga: sound-pattern extraction and clustering for Sanskrit kavyas. Processing notebooks and scripts live under `varna-sanyoga/` (preprocess, extraction, clustering, feature analysis). See `varna-sanyoga/README.md` for full instructions and dependencies.
- shrikaanta-charitam: text processing and compiled outputs for the Shrikaanta Charitam text (compiled TSV, HTML, PDF outputs).

Quick start

1. Browse subfolders to find notebooks and scripts relevant to each project.
2. For Python-based analyses, use a virtualenv and install dependencies from the respective `requirements.txt` files (for example `linguistics/varna-sanyoga/requirements.txt`).
3. Use the included notebooks for exploratory work; scripts can be run from the command line.

If you'd like a more detailed README for a subproject, open an issue or edit the appropriate subfolder README directly.
